# 🛡️ 금융권 API 취약점 악용 대규모 고객 데이터 유출 시뮬레이션

**프로젝트 기간**: 2026.10.07 ~ (진행 중)  
**사용 기술**: Rocky Linux 9, MariaDB, PHP, Python, Apache  

## 📝 프로젝트 개요
최근 금융권에서 발생한 '업무용 API 취약점을 악용한 자동화(Bot) 데이터 스크래핑' 해킹 사건을 모티브로 한 모의 훈련 프로젝트입니다. 
인프라 구축부터 취약점 공격(Red Team), 침해사고 로그 분석 및 시큐어 코딩(Blue Team)까지 전 과정을 직접 시뮬레이션하며 보안 실무 감각을 익힙니다.

* Day 2: Insecure Direct Object Reference (IDOR) 수동 취약점 분석 (예정)
* Day 3: Python 기반 무작위 대입(Brute-force) 자동화 스크래핑 공격 (예정)
